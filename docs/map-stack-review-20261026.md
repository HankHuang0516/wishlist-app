# 地圖縮圖堆修正（2026-10-26）

Android 38 的實機回饋指出：地圖一進入便展開全部60件商品。新版改為預設顯示依實際投影位置分組的縮圖堆；只有手動點選某堆才展開全部成員。點空白處或收合按鈕收回，Web另支援Escape並還原焦點。拖曳／捲動不應誤當空白點擊。一般展開400ms、收合240ms，尊重系統減少動態效果。

分組不修改公開座標、不限制成員數；缺照片仍保留商品。原Golden14圖片作展開後分類排列參考，不能再當預設入口。查詢、同條件列表返回、來源及參考原價沿用原有流程。

Web與原生均在真實地圖樣式就緒後啟用投影，不再等待每一圖塊完整載入；圖塊載入問題仍保留提示與同條件列表退路。稍後完整載入事件不可重新fit或收合使用者已展開的內容。

另修正商品詢問API限流的跨功能影響：原本未分類429會暫停獨立的願望寫入。伺服器現在回傳明確的商品詢問限流代碼，Web只對該路由建立期限。原120/IP及30/使用者上限、Retry-After及一般傳輸限流保留；不自動重送寫入。
