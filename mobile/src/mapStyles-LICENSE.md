# OpenFreeMap Liberty map style attribution

`libertyZhHantStyle.ts` is a 2026-09-28 snapshot of the OpenFreeMap Liberty
style from <https://tiles.openfreemap.org/styles/liberty>. It modifies only
symbol-layer name expressions to prefer Traditional Chinese (`name:zh-Hant`),
then Chinese (`name:zh`), then the local name, with English as a final fallback.
Tile, sprite and glyph URLs still point to OpenFreeMap. Map data is from
OpenStreetMap contributors: <https://www.openstreetmap.org/copyright>.

The [OpenFreeMap styles license](https://github.com/hyperknot/openfreemap-styles/blob/main/LICENSE.md)
lists the repository under MIT and Liberty's upstream OSM Bright style code
under BSD 3-Clause with its design under CC BY 4.0. The upstream Liberty style
is <https://github.com/maputnik/osm-liberty>. Preserve MapLibre's visible
attribution control and this notice when distributing a bundled style.
